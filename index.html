⚙️ Apps Script 연결 설정

처음 한 번만 설정하면 됩니다.
Code.gs를 Apps Script에 배포한 후 URL을 붙여넣으세요.

  1. Google 스프레드시트 새로 만들기
  2. 확장 프로그램 → Apps Script
  3. Code.gs 내용 전체 복붙 후 저장
  4. 배포 → 새 배포 → 유형: 웹 앱
  5. 실행: 나 / 액세스: 모든 사용자
  6. 배포 완료 후 URL 복사

URL은 이 기기에만 저장됩니다.
